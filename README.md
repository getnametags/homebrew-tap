# Nametags for Homebrew

```
brew install --cask getnametags/tap/nametags
```

[Nametags](https://www.nametags.site) puts your name, role and company on your
video, in Zoom, Teams, Meet, Webex and anything else that reads a camera.
Apple silicon, macOS 13 or later.

The app updates itself once installed, and `brew upgrade` follows releases too.

The cask is updated by `scripts/homebrew.sh` in Nametags' release process, so
there is nothing to edit here by hand.
